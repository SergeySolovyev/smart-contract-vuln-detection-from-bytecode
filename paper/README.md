# Paper sources (v2)

LaTeX sources for the v2 paper. `numbers_v2.tex` is GENERATED by
`scripts/emit_macros_v2.py` from `results/` — do not edit it by hand.
The body cites only those macros, and `scripts/check_numbers_v2.py`
reads the BUILT PDF and fails on any disagreement with the artifacts,
so a number cannot drift between the results and the prose.

The v1 sources that used to sit here have been removed: they describe
the retracted protocol, and keeping them beside v2 results invited
exactly the confusion this rerun was meant to end.

Build:

```bash
pdflatex -interaction=nonstopmode main_v2 && bibtex main_v2
pdflatex -interaction=nonstopmode main_v2 && pdflatex -interaction=nonstopmode main_v2
```

The compiled PDF is not committed; it is published via figshare with a
DOI, and a binary in git would be a second copy free to drift.
